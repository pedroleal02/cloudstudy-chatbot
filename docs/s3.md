# Armazenamento de documentos (S3)

## Finalidade
Guarda os documentos de estudo que o tutor usará como base de conhecimento.
Neste momento, apenas armazenamento: a busca contextual ainda não está integrada.

## Bucket
- Nome: tutor-docs-pedrolima-2026
- Região: us-east-1
- Acesso público: bloqueado
- Criptografia: SSE-S3
- Versionamento: ativado

## Estrutura
documentos/<disciplina>/<arquivos>
- nomes em minúsculas, com hífens, sem espaços e sem acentos
- formatos aceitos: .md, .txt, .pdf

## Permissões
- Role da Lambda: leitura (s3:GetObject e s3:ListBucket) apenas em documentos/*
- Escrita: somente pessoas do grupo, direto pelo console ou CLI
- Política da Lambda em iam/lambda-s3-read-policy.json

## Como adicionar documentos
aws s3 cp arquivo.md s3://tutor-docs-pedrolima-2026/documentos/<disciplina>/arquivo.md

## O que não enviar
Dados pessoais, senhas e material com direitos autorais restritos.
